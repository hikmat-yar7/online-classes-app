# 🎓 Career Vision

### Learn Today, Lead Tomorrow.

Career Vision is an online coaching platform inspired by modern EdTech applications like PW (Physics Wallah).

Our mission is to provide quality education to students through online courses, video lectures, study materials and online tests.

---

## 🚀 Features

- 🏠 Modern Home Page
- 👨‍🎓 Student Login & Signup (Demo)
- 📚 Classes 1 to 12
- 🎯 JEE & NEET Preparation
- 🎥 Live Classes (Coming Soon)
- 📖 Study Materials (Coming Soon)
- 📝 Online Tests (Coming Soon)
- 👤 Student Dashboard
- 🔐 Admin Panel (Coming Soon)
- 📱 Mobile Responsive Design

## ▶️ How to Run

1. Download and install Acode.
2. Create a folder named Career-Vision.
3. Create these files:
   - index.html
   - style.css
   - script.js
4. Paste the project code into the respective files.
5. Save all files.
6. Open index.html in Preview mode.
